First Alert API Alert Delivery Method
Summary
Dataminr’s First Alert product for the public sector alerts first responders to breaking news events,
enabling the fastest real-time response.
This document details First Alert’s RESTful API endpoints that allow for authentication and delivery of First
Alert’s breaking news Alerts based on the settings you have configured in your First Alert web application.
All requests are made via secure HTTP (HTTPS) and data flow is unidirectional. Response data is returned
in JSON format.
By using the First Alert API Alert Delivery method, you agree to the terms found here:
https://www.dataminr.com/firstalert-thirdpartytermsapi

Security Measures
In order to receive breaking news alerts with the First Alert API alert delivery Method, HTTPS
connections are required when sending requests.
Authentication and Credentials
For server-based applications, you are assigned an API User ID and API Password associated with a single
user account in the First Alert Web Application, which work the same as a Client ID and Client Secret
respectively in the standard OAuth 2.0 framework.
To retrieve your API User ID and API Password, you must log into your API delivery method-enabled
First Alert account using your First Alert account credentials.
Within First Alert, click Settings in the upper right and select Account. Then select the API Authorization
tab on the left and click Manage API Authorization. Re-enter your First Alert credentials and follow the
prompts to accept terms of service and authorize API delivery. Once successfully authorized, you will see
your API User ID and API Password. Be sure to store in a secure location.
NOTE: The First Alert API functions as an alert delivery method for the First Alert account and its
alert setting. At least one (1) valid Alert List must be configured on the account before making API
calls.
To request alerts, an Authorization Token must first be obtained from the Dataminr Authorization Service
and included in subsequent requests for that session. To retrieve your Authorization Token, use the API
User ID and API Password obtained via the First Alert API authorization workflow described above to call
the /userAuthorization endpoint, outlined below:

Rate Limiting
In order to protect the Dataminr service, some of the APIs may have an associated rate limit or the
number of calls that can be made over a period of time by a specific user account. Exceeding the rate
limit may result in a failed request and an HTTP 429 error returned.

Cursor-Based Implementation
The First Alert API alert delivery method uses a cursor-based implementation to paginate through alerts.
The response from the API alert delivery method returns a to cursor pointing to the most recent of the
returned alerts. To retrieve a stream of alerts without duplicates, you should pass the returned to value
from the previous request as the following request’s from parameter. Ensure that cursors are URL
encoded when making requests.

API Alert Delivery Method Implementation Best Practices
The First API alert delivery method is a pull-based API, meaning that you have the ability to have alerts
delivered at an interval of your choosing. Depending on system limitations and requirements, requests
can be made as quickly as every few seconds. Generally, due to the importance of real-time breaking
news alert delivery, we suggest that alerts are pulled every 15 seconds. In situations where system
performance is a priority, you may pull alerts less frequently. However, make sure that alerts are
delivered frequently enough relative to your alert settings.

should be processed to provide ease of troubleshooting and possible logging.

FAQ’s and Troubleshooting
● How can I configure alerts lists directly via the API alert delivery method?
○ Answer: You cannot create or configure alerts lists via the API alert delivery method. All
alert configuration must be done in the First Alert web application. The API alert delivery
method only allows for the delivery of the breaking news alerts that have been configured
in your First Alert account.
● Why am I not seeing any alerts coming through the API alert delivery method? ○ Answer: Each
alert list can have its delivery method configured to determine whether it is delivered via API.
Ensure the alert delivery methods are configured to your requirements.
