Answers to the three questions
1. Which intake paths each is configured for. There are six callers of the curated admission function (admitCuratedCandidates):

Direct curated RSS (curatedIngest.ts → reads curatedFeeds.ts): all four are explicitly omitted, with a code comment stating their public RSS is dead/blocked/frozen.
RSS-bot reject path (rssFeedBot.ts, capped 60/cycle): rssFeeds.ts still lists all four, but with the same dead URLs (feeds.apnews.com, feeds.reuters.com, rss.cnn.com, feeds.npr.org), so it yields ~nothing for them.
Drudge website-scraper reject path (scraper.ts, capped 50/cycle): this is what actually feeds them — Drudge surfaces apnews/npr/reuters links, the scraper grabs them, and the ones that fail the main CJCS relevance gate (the least relevant) get dropped into curated.
Plus team submissions, social, and CPC paths (not relevant here).
2. Do the configured feeds work right now? Verified by DNS + curl from the server:

feeds.apnews.com → ENOTFOUND (dead) · feeds.reuters.com → ENOTFOUND (dead) · feeds.npr.org → HTTP 403 (blocks our datacenter) · rss.cnn.com → HTTP 200 but frozen/old content.

Important nuance: the dedicated apNewsBot/reutersBot scrapers only post their CJCS-relevant articles to the main feed and discard the rest — they never write to curated. So the reject path that feeds curated is the generic Drudge one, not the wire bots.

Recommendation (narrow fix — for a future pass, not done here)
The wire bots already scrape working hosts (apnews.com, reuters.com resolve fine — only the feeds.* RSS subdomains are dead). The clean fix:

AP & Reuters: In apNewsBot.ts / reutersBot.ts, collect the non-relevant articles they currently drop (right after the relevance filter) and pass them to admitCuratedCandidates(..., { mode: 'gate', label: 'apnews-direct' / 'reuters-direct' }) — mirroring exactly what scraper.ts and rssFeedBot.ts already do. This gives both a dedicated, recurring direct curated intake from a live host. Isolation stays intact because that function writes only to curated_items.
NPR: No dedicated scraper, but it's already getting reasonable volume (12) via Drudge. Lowest priority; could add a small npr.org website scraper with the same reject hook if more breadth is wanted.
CNN: The real gap — 0 curated rows, frozen RSS, no scraper. Needs either a small cnn.com website scraper (with the reject hook) or a currently-working CNN feed (e.g. a lite.cnn.com source).
